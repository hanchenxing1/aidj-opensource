欢迎使用 AIDJ 单机版

首次使用需配置 API key（模型生成能力由 new.aiwyq.bond 网关提供）。
全程约 1 分钟，key 只保存在本机，不会上传任何服务器。

🔑 与网页端同一账号

在 dj.aiwyq.bond（网页端）注册的账号，可直接登录单机版， 订阅、余额、权益自动同步；单机版生成的短剧全部保存在本机，网页端只负责记账。

去登录 / 注册 ↗
1

注册并获取 API key

点击下方按钮打开 new.aiwyq.bond 控制台， 使用邮箱注册账号（免费开通），在控制台复制你的 API key（sk- 开头）。

打开 new.aiwyq.bond 控制台 ↗
2

粘贴 key 并保存

把复制到的 key 粘贴到下方，点击保存（可多把 key 用换行分隔，用于提高并发额度）。

保存成功。请关闭本窗口并选择「停止服务」，再重新打开，key 即生效； 或稍后在「个人中心 → API」查看。
